# Le Martini · Behind the Bar

An endless React bartending game inspired by Rozzo’s 124 BPM single Le Martini. Serve guests by choosing ingredients and tapping the matching order. Five guests walking out in a row ends the shift.

Run `npm ci` then `npm run build` to bundle the React app. Preview the repository with `python3 -m http.server 8000`. Commit the rebuilt `game.bundle.js` with source changes because GitHub Pages serves the static files from this repository.
