# Le Martini · Behind the Bar

A 90-second browser bartending game inspired by Rozzo’s 124 BPM single Le Martini.

Serve the guests by selecting ingredients and tapping the correct order. Recipes and ingredients unlock as the shift progresses. All game files are static. To preview locally, run `python3 -m http.server` in the repository root and open `http://localhost:8000`.
